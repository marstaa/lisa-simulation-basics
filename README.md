# lisa-simulation-basics
Basic tutorials on the LISA Simulation Suite (LISA Orbits, LISA Instrument and PyTDI)

## Run on Google Colab

Open the notebooks in Colab:

- example LISA instrument simulation workflow: [simulation_example.ipynb](https://colab.research.google.com/github/marstaa/lisa-simulation-basics/blob/main/simulation_example.ipynb)
- exercise LISA Orbits: [lisaorbits_exercise.ipynb](https://colab.research.google.com/github/marstaa/lisa-simulation-basics/blob/main/lisaorbits_exercise.ipynb)
- exercise LISA Instrument: [lisainstrument_exercise.ipynb](https://colab.research.google.com/github/marstaa/lisa-simulation-basics/blob/main/lisainstrument_exercise.ipynb)
- exercise PyTDI: [pytdi_exercise.ipynb](https://colab.research.google.com/github/marstaa/lisa-simulation-basics/blob/main/pytdi_exercise.ipynb)

## Run locally

Create an environment with the tool of your choice and install the required packages using e.g. `pip install numpy scipy matplotlib lisaorbits lisainstrument pytdi`, then open the notebook in Jupyter or VS Code and select the environment's Python kernel.
